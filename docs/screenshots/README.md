# SpaceWorks screenshot gallery

These actual browser captures show the local **0.9.0 development application** with synthetic
demonstration data. No production borrower, member or payment information was used. A screenshot
shows the rendered page; it does not prove that every visible action was executed.

The refresh currently contains **77 captures**. The page and dialog coverage below is an inventory of
saved images, not a claim that every workflow state is illustrated. Additional public account/detail
and recovery states are outside this gallery; runtime verification is recorded separately in the audit
report. Older images outside `2026-10/` are historical and are no longer used by the main README.

The check-in layout uses a separately labelled synthetic makerspace and a reserved `example.test`
roster URL. No roster lookup or identity verification was performed. The name field and request card
were checked at 1280px and 320px: the input border remains complete and the borrow form uses normal
page scrolling, with no nested or horizontal scroll. The machine Running capture was followed by
restoring the synthetic machine to its original Idle status.
